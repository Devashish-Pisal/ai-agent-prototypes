# AI Agent Prototypes

A collection of traditional AI/ML algorithms implementations, AI agents and workflow automation prototypes built while exploring practical applications of traditional AI/ML algorithms, LLMs, APIs, and process automation.

---

## Projects

| Project              | Description                                                                                                                                               |
|----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| Commission Predictor | A machine learning pipeline that predicts the expected commission of a marketplace sales request, combining a conversion classifier with a fee regressor. |
| Email Invoice Agent  | Scans an email inbox, detects invoice emails, downloads PDF attachments, verifies them with an LLM, and stores them in a folder.                          |

---
